## Fitur Aplikasi

- **Ringkasan Pesanan**
  - Jumlah pesanan aktif.
  - Jumlah pesanan selesai.
  - Pendapatan dari pesanan selesai.
- **Formulir Pesanan**
  - Nama pelanggan.
  - Nomor HP.
  - Berat cucian.
- **Pilihan Layanan**
  - Reguler.
  - Kilat.
  - Setrika saja.
- **Pewangi Premium**
- **Estimasi Tagihan**
- **Penyimpanan dan Pengelolaan Pesanan**
- **Riwayat Pesanan**

## Cara Menjalankan Proyek

1. Clone repositori:

   ```bash
   git clone https://github.com/alvinseptian22/uts-pbm-2026-kelompok-02.git
   ```

2. Buka proyek di Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Jalankan aplikasi menggunakan emulator atau perangkat Android.
